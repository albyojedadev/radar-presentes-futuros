# 🌐 Radar de Presentes & Futuros

Plataforma integral de inteligencia geopolítica, monitorización continua de portadas globales (Radar de Presentes) y contraste empírico de hipótesis prospectivas (Radar de Futuros).

---

## 🚀 Arquitectura y Capacidades

- **Módulo 1: Radar de Presentes (En Vivo):** Mapamundi vectorial interactivo con los 9 bloques geopolíticos (España, Francia, Alemania, UK, UE, EEUU, Latinoamérica, África y China). Desglose en tiempo real de titulares traducidos, nivel de polarización superficial y corrientes subterráneas.
- **Módulo 2: Hemeroteca Semanal (2020–2026):** Archivo cronológico navegable con **357 semanas** indexadas. Cada titular incluye enlace canónico a las fuentes primarias para "Tirar del hilo".
- **Módulo 3: Anuarios Estratégicos:** Auditorías de segundo orden de cada año (Campañas de Humo desmentidas vs Puntos Ciegos descubiertos vs Framing geopolítico).
- **Módulo 4: Radar de Diseño de Futuros:** Matriz de hipótesis prospectivas falsables a 3, 5 y 10 años con medidores de tracción y feed cruzado de **Señales a Favor (🟢)** y **Señales en Contra (🔴)**.

---

## ⚡ Sincronización Continua a 0€

Los scripts locales de Python en `_AUTOMATIZACIONES_E_INFORMES_/RADAR_DE_PRESENTES/` actualizan el dataset diariamente y ejecutan un `git push` automático a la rama `main`, desencadenando el autodespliegue en Vercel en <30 segundos sin necesidad de bases de datos externas.

---

## 🛠️ Stack Tecnológico

- **Framework:** Next.js 15 (App Router) + React 19
- **Estilos:** Tailwind CSS (Dark-First Theme)
- **Iconografía:** Lucide React
- **Animaciones:** Framer Motion
- **Despliegue:** Vercel + GitHub CI/CD
